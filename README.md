# ChangeTextInImage: feedback and bug reports

[ChangeTextInImage](https://changetextinimage.app) replaces text inside an image and keeps the original lettering. Upload a picture, draw a box around the words, type the current and the new text, and press Change text. The first edit is free, with a watermark and no sign-up.

ChangeTextInImage is operated by Summercloude Pte. Ltd., Singapore (UEN 202619506N).

This repository is where you can report a problem or suggest a feature.

## Report a problem

[Open an issue](https://github.com/SummerCloude/changetextinimage-feedback/issues/new) and tell us:

- the current text and the new text you typed
- what came out instead
- the browser and device you used

Issues here are public. Please don't attach images with personal information. For anything about a payment or your account, email support@changetextinimage.app instead.

## Good to know

- Works best on English text. Chinese text doesn't work yet.
- The AI redraws the whole picture, so small text outside your box can change slightly. Check the whole result before you use it.
- One edit can hold up to 5 text changes and uses 1 credit. Packs start at $4.99, with no subscription.
- If the new words don't come out right, the free preview or the credit is given back automatically.
- Not allowed: identity documents, receipts, invoices, certificates, and screenshots of payments or messages.
